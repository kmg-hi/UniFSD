# Figure preparation queue

No images have been selected or copied. Before using representative real/public
frames, verify attribution, redistribution and privacy. Record sample IDs, data
version, modalities, any crop/overlay and any display scaling in the figure legend.
For thermal panels state that they are processed colour views, not temperatures.

A useful compact overview is an original curation/record-relationship diagram
and a small representative paired example after clearance. Registration/annotation
quality figures belong to actual technical validation, not invented statistics.
Prior model comparison charts are not automatically the appropriate main figures
for a Data Descriptor.
